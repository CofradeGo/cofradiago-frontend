# CofradíaGo - Guía de Estilo (Desktop-first)

## Colores

- brand-500 / brand-700 → primarios
- accent-500 → resaltos
- gray-50 / gray-100 / gray-200 → backgrounds

## Tipografía

- Inter, sans-serif
- Tamaños: base 16px, lg 18px, xl 24px

## Espaciado

- 4,8,12,16,24,32,48 px

## Componentes

- Atoms → Button, Input, Typography
- Molecules → Card, FormGroup
- Layouts → AuthLayout, DashboardLayout
- UI → EmptyState, Spinner

## Layout

- Desktop-first
- Sidebar + topbar para Dashboard
- Formularios centrados en AuthLayout

## UX

- Accesible: focus visible, contraste WCAG AA
- Feedback visual en botones/inputs
