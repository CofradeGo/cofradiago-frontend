# Cofradías Semana Santa - Frontend

## Descripción
Proyecto frontend para gestionar las cofradías y cortejos de Semana Santa.  
Desarrollado con **React + TypeScript + Vite**. Permite configurar cofradías, gestionar miembros y estaciones de penitencia.

## Tecnologías
- React 18
- TypeScript
- Vite
- TailwindCSS
- ESLint & Prettier
- Husky + lint-staged

## Estructura del proyecto
src/
├─ components/ # Componentes reutilizables
├─ pages/ # Vistas principales
├─ services/ # Conexión con backend
├─ styles/ # Estilos globales
└─ App.tsx # Punto de entrada


## Scripts
- `npm install` → Instalar dependencias
- `npm run dev` → Levantar servidor de desarrollo
- `npm run build` → Compilar proyecto para producción
- `npm run lint` → Ejecutar ESLint
- `npm run format` → Formatear con Prettier

## Contribución
Sigue el flujo de **git feature branches** y abre Pull Requests hacia `develop`.
